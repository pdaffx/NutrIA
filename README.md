# NutrIA
NutrIA — nutrição e bem-estar no seu ritmo
Transforme suas refeições em escolhas mais conscientes. Envie uma foto do prato para identificar alimentos e estimar porções, calorias, proteínas, gorduras e carboidratos. Ajuste os itens detectados e registre tudo no diário alimentar.
Defina seu perfil e acompanhe metas personalizadas de calorias e macronutrientes. Gere planos de refeições, consulte uma base com mais de 85 alimentos brasileiros e use calculadoras de TMB, TDEE, IMC, hidratação, frequência cardíaca e outras métricas.
Com visual adaptável para celular e computador, o NutrIA reúne nutrição, planejamento e acompanhamento diário em um só lugar. O diário e os cálculos ficam salvos no navegador; a análise de fotos por IA requer internet e uma chave de API compatível.
